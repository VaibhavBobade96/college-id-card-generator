# Project Nmae
college-id-card-generator

# Description
This project is a College Student ID Card Generator developed using HTML, CSS, JavaScript, and Python. It allows users to enter and manage student details such as name, photo, roll number, and department. The system stores all student information in an SQLite database for efficient data management. Using automated processing, the application can generate professional ID cards for more than 500 students at a time with a single click, making the process fast, efficient, and reducing manual work in colleges.

# Features
- Automatic ID card generation
- Generate ID cards for 500+ students in a single click
- Add a single student using a student registration form
- Upload student data using a CSV file
- Batch-wise student data management and ID card generation
- Bulk upload student images using a ZIP folder
- Download generated ID cards in PDF and PNG formats
- Search students by student code or name
- Edit and update student information
- Delete student records from the database
- Promote passed students from one class or batch to the next academic batch

# Technologies Used
- HTML – for structuring the web interface
- CSS – for styling and design
- JavaScript – for client-side interactivity
- Python – for backend logic
- Flask – Python web framework used to build the web application
- SQLite – database used to store and manage student data
